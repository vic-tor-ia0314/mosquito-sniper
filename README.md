# mosquito-sniper
Welcome to our Sunbeam game jam submission! In this game, you have to shoot mosquitoes (Space Invaders-style) with different beams/bullets. Each mosquito gives you one point,
and levels increase in total points as the game goes on. When you reach two base thresholds of level 3 and level 6, then you unlock corresponding special bullets that allow
you to kill mosquitoes more easily. Use arrow keys to move and space, R, and Q to shoot. Good luck!
